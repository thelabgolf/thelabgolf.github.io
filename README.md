# The Lab

**Understand the Game. Master Your Game.**

Golf education and personal training app in development.

## Development status

Prototype v0.5 exists as a local development package. Its full application files have not yet been uploaded to this repository. This README is the first development documentation commit.

Planned modules: The Academy, My Programs, Practice Center, Swing Lab, My Golf Bag, Round Tracker, Golf IQ, Ask The Lab, and My Lab.

## Media roadmap

- Match specific permitted-to-embed videos to individual lessons and drills.
- Create original instructional diagrams.
- Add properly licensed instructional photos and descriptive captions.
- Test accessibility, mobile playback and source links.

## Repository safety

The owner has approved keeping this repository **public**. Do not upload secrets, account information, or the owner's private OPERATION REBUILD curriculum. No public website deployment is intended yet.
